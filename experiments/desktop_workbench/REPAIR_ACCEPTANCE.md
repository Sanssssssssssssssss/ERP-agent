## 环境与剩余边界

- 0.4.0 为未签名 Windows 试用构建。对外客户 Demo 仍需从普通对话开始复跑完整写入、审批、取消/中断与核对旅程。
- 只读任务当前仍使用销售开票基础阶段与核验规则；页面展示“已确认/已过账”代表观察到的事实，不能据此声称本轮执行了这些动作。更多业务模板与目标对应验收需后续扩展。
- 真实试跑消耗只用于证明链路与交互，不是对照实验；本轮没有可声称的 token 节省比例。
- 原隔离 Odoo 容器启动器试图重复恢复快照而拒绝启动。本次从原容器层创建恢复镜像/容器，保留原容器和数据库，复用原 filestore；绑定仍为 18069。临时 WSL 保活用于验收，部署时仍需正常常驻 Odoo 服务。
- 原用户 profile 与验收 profile 分开。升级必须保留完整 profile（包括 `data`、`settings.json` 与 `Local State`），不能只复制加密设置文件。不会把验收会话伪装成用户旧会话。
