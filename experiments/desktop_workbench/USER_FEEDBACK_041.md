## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| 发送后首段文字出现前像没有响应 | 立即显示 Agent 头像和“正在思考…”；公开文字到达后消失。覆盖连续发送、失败后重试、切换会话、运行快照恢复、停止状态。 |

| 能力回答让人误以为只能审批 | 明确能够在审批后创建订单、确认订单、生成并过账关联发票；无需用户先手工建票。附件上传、OCR、付款、采购和制造不作为当前桌面已交付能力承诺。 |
| 只有“销售与开票”也生成泛化目标 | 会话先问客户及具体动作；已有单号或粘贴文字均可。真实复测原话时只补问，没有提案或业务。明确只读浏览待处理订单仍可进入相应提案。 |

补问规则属于模型指引，服务端提案协议仍只校验类型、文本和长度，不能当作业务完整性的硬性校验。每项写入的审批、权限及状态校验继续由原生执行器负责。
