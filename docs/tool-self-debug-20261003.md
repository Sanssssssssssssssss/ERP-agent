## 修复与保护

- 共用异常入口保留稳定原因、故障层及下一步；员工和假期响应模型保留这些字段。未知原因继续标未知。
- 诊断按宿主维护的分类生成指引，保留 SOP 缺项和可信的证据目录恢复请求。关联冲突、未结束的 RPC 与待核对写入优先显示。
- 动作保留准备、发送、核验阶段和账本状态；发送后读回失败需要核对，不能自动重放。
- 后台任务的返回失败也进入 failed 状态；轮询显示 execution_failure。跨实例保留成功结果和各实例失败。Knowledge 来源与刷新失败保留底层原因。
- 运行时参数拒绝进入下一次模型请求正文；动态发布异常还原选择。原生 Odoo 路径、字段策略和逐动作审批继续由现有回归保护。
