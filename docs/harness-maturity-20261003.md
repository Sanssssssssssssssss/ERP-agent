已核对 transport、session 与 Harbor 三层重试：transport 为 0；无显式预算时 session 仍可恢复暂态错误；Harbor 的 0 只约束外层重跑。桌面已有 watchdog，但主入口显式选择无总限时；保留该约定，不恢复 8192 输出上限。相关 65 项测试、23 项子测试通过，见[日志](../.runtime/harness-maturity-20261003/core-boundaries.log)。
