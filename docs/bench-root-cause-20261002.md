## 根因与小范围修复

- **字段发现：**最早的错误是未查现场版本便请求旧字段。上轮新增的恢复回包又使用了未公布的裸工具名。本轮将恢复工具名对齐公开契约，并带回原实例，避免跨连接查询。候选字段仍是建议；`capacity_ids` 是关联字段，不能替代旧的标量容量字段。
- **最终业务核验：**原错误把采购来源当作单号字符串，没有校验来源销售能承接的商品数量。2010 为采购10、来源需求7；2030为采购6、来源需求4。原四题配置没有启用严格宿主契约。本轮将两题的商品、客户与竞争采购范围显式绑定到 [原指令来源](../experiments/agent_regression/bench-regression-20261002/recovery-scopes.json)，用现有宿主核验执行。
- **预付款行：**真实2030快照首次核验因零数量行缺少单位而返回未知。共享核验器现在跳过不贡献数量的零数量行；非零、负数及单位缺失继续保持未知。

生产改动限于两个文件中的5行。其余改动用于纠错上下文、回归与证据。
