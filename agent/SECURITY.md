# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Sanssssssssssssssss/pi-agent-python/security/advisories/new)
so details can be reviewed before disclosure.

Include the affected version, reproduction steps, impact, and any suggested mitigation.
You should receive an acknowledgement within seven days.

## Supported versions

Only the latest published release receives security fixes. Until the first release,
security fixes target `main`.
